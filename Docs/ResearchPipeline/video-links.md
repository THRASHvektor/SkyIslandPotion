# 好视频链接清单（人工维护）

> 视频爬取困难（yt-dlp 被限速/网络不可达），改为人工维护此清单。
> Agent 不自动爬取视频，只在此清单的基础上做后续处理（下载、ingest、LaTeX）。

## 维护方式

1. 你在 YouTube/Bilibili 发现好视频，直接在这里加一行
2. 格式：`- [标题](URL) | 来源 | 简短理由`
3. Agent 定期检查此清单，对新条目执行 ingest 流程
