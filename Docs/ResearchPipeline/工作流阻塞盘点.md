### 阻塞 2：Agent-Reach 安全扫描 100 分（🟡 待拍板）

**SkillSpector 扫描结果**：
- 风险分：**100/100**
- 严重度：**CRITICAL**
- 建议：**DO_NOT_INSTALL**
- 总 findings：183 个（73 HIGH, 109 MEDIUM, 1 LOW）

**按 spec §8 规则**：51+ 不装。100 分超出范围，**严格按 spec 不应该装**。

**但我的分析**：183 个 findings 里，绝大多数是**功能命中**，不是真恶意：

| 类别 | 数量 | 分析 |
|------|------|------|
| Env Variable Harvesting | 多次 | 命中 `os.environ.get("GROQ_API_KEY")` — 检查 Whisper API key，**是功能** |
| Credential Access | 多次 | 命中 `credential.json` / `.env` / `Keychain` — 读写用户自己的平台凭证，**是核心功能** |
| Data Exfiltration | 27 | 命中发数据到外部 URL — 但都是发到**用户指定平台**（Twitter/Reddit/B站 API） |
| YARA info_stealer | 4 | 命中"从浏览器读 cookie" — 但这是 `--from-browser` 功能的**设计意图** |
| External Script Fetching | 3 | 命中 `curl | bash` — 但这些在**安装建议文本里**，不是代码自己执行 |
| Session Persistence | 8 | 命中写凭证到 `~/.config/` — 但代码用 **0o600 权限**创建文件 |
| Direct Prompt Extraction | 2 | 命中"print instructions" — 实际是打印安装指引给用户看 |
| Tool Parameter Abuse | 1 | 命中 **PNG 文件里的二进制数据** — 明显误报 |

**真实风险点**（值得注意的）：
1. `--from-browser` 会自动提取**所有平台**的浏览器 cookie — 如果用户没明确授权，是不安全的
2. `SC4 Known Vulnerable Dependency`：pyproject.toml 的 `requires-python` 有 MAL-2025-41747 advisory
3. 代码处理 Twitter/Reddit/小红书 等平台的登录 cookie — 如果泄露等于账号泄露

**但代码有以下安全措施**：
- cookie 只存本地 `~/.agent-reach/config.yaml`，权限 0600
- 不上传 cookie 到任何第三方
- 有 `--safe` 安装模式（不自动装系统包）
- 代码完全开源

**结论**：100 分主要是 SkillSpector 的静态规则把"读写 cookie/credential"这个核心功能判成了恶意行为。大部分是**误报**。但 `--from-browser` 批量提取 cookie 的能力是真实的权限需求。

**这需要你拍板**：
- 按 spec 严格规则：不装
- 按我的分析：可以装，但要避免用 `--from-browser`，改用手动 Cookie-Editor 导出
- 如果装：用 `agent-reach install --env=auto --safe`（安全模式）

## 六、你需要做的决定

### 决定 1：Agent-Reach 装不装？

扫描 100 分 CRITICAL，但分析显示大部分是功能命中（cookie 读取是核心功能）。按 spec §8 严格规则不装。

- **装**：用 `--safe` 模式，避免 `--from-browser`，手动 Cookie-Editor 导出 cookie
- **不装**：调研工作流退回到 web-access CDP 模式（通过浏览器抓取，但需要你开 CDP）
- **先看代码再决定**：我可以把 Agent-Reach 的关键文件列给你看

### 决定 2：网络代理

Reddit / GitHub API 全部超时。discover.py 要跑通必须有可达的网络。

- **你有代理吗？** 如果有，告诉我代理地址（`http://127.0.0.1:7890` 之类），我配 `HTTP_PROXY` 环境变量后重测
- **用 web-access CDP？** 如果你的浏览器已经能访问 Reddit/GitHub，可以走 CDP 模式
- **换环境？** 在能直达这些站点的机器上跑 discover.py

### 决定 3：浏览器 CDP

如果走 web-access CDP 模式，需要你在 Chrome 或 Edge 里：
- 打开 `chrome://inspect/#remote-debugging`（或 `edge://inspect/#remote-debugging`）
- 勾选 "Allow remote debugging for this browser instance"
- 可能需要重启浏览器
